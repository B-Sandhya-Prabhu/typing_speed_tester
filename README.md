# Cyber Typer 3000 - OpenGL Typing Speed Game

A modern, cyberpunk-themed typing speed game built with PyOpenGL and Pygame.

## Features

- Real-time 2D rendering using PyOpenGL
- Dynamic cyberpunk-inspired visual effects
- Falling letter animation with increasing difficulty
- Score tracking system based on speed and accuracy
- Combo system with visual feedback
- Experience and level progression
- Particle effects and visual feedback
- Animated HUD with game statistics

## Requirements

- Python 3.11+
- Pygame
- PyOpenGL
- PyOpenGL-accelerate

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/typing-speed-game.git
cd typing-speed-game
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## How to Play

Run the game:
```bash
python typing_game.py
```

- Type the letters as they fall from the top of the screen
- Don't let letters reach the bottom
- Build combos for higher scores
- Level up to increase difficulty and rewards

## Controls

- Type the corresponding letters on your keyboard
- Any key to restart after game over
- Close window to quit
